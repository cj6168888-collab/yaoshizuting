# 推广码美工升级设计

## 目标

将当前“我的推广码”从功能型二维码卡片升级为可转发、可截图、可促成新客扫码的裂变转化海报。主方向采用视觉伴随页中的 C 方案：活动感更强，动作更明确，但保留药师祖庭的深绿、鎏金、米白品牌调性，避免廉价秒杀感。

## 使用场景

- 会员在后台/移动端打开“我的推广码”，截图或复制链接发给好友。
- 门店员工现场向客户展示推广码，引导扫码注册并绑定推荐关系。
- 已报名活动用户在“我的”页面点击“我的推广码”，继续分享好友，形成二次传播。

## 页面结构

推广码页保留当前邀请链接和二维码数据来源，不新增后端接口。

页面主体分为两栏：

1. 左侧为可截图海报预览。
2. 右侧为推广说明、复制链接、保存提示、绑定关系工具。

在窄屏下，两栏改为单列，海报优先显示。

## 海报内容

海报采用 9:16 移动海报比例，适合手机截图和微信转发。

顶部：
- 品牌小标：药师祖庭
- 强提示条：好友报名 · 到店加赠

主标题：
- 分享好友
- 一起领体验

副文案：
- 新会员扫码注册，系统自动绑定推荐关系。
- 到店出示核销券，即可参与门店活动。

权益块：
- 新人体验券
- 好友报名提醒
- 我的推广码
- 我的核销券

二维码区：
- 白底大二维码
- 文案：长按识别二维码
- 邀请人：显示 `parentNickname`，为空时显示“药师祖庭会员”
- ID：显示 `parentId`

底部合规提示：
- 本服务为日常康养体验，不替代医疗诊疗。

## 视觉规则

主色：
- 活动青绿：用于主背景和行动氛围。
- 药师祖庭深绿：用于品牌区、底部区、重要文字。
- 鎏金：用于标题高亮和标签点缀。
- 米白：用于二维码卡片和信息承载。
- 朱红：仅用于顶部活动提示，不大面积使用。

版式：
- 背景可以有轻微纵向渐变，但不使用紫蓝渐变、装饰光球或过度营销背景。
- 海报卡片圆角保持 8px 左右，按钮和信息块不做过大圆角。
- 二维码区必须足够大、对比度强，优先保证扫码识别。
- 文案控制在 2-4 行内，避免堆砌。

## 交互

- 复制链接：继续使用当前 `copyInviteLink`。
- 保存海报：当前阶段保留提示式交互，文案升级为“当前海报可截图保存；后续可接入一键生成图片”。
- 查看好友：若当前项目已有团队/好友入口，则跳转团队菜单；如果没有明确入口，先作为低风险提示，不新增后端功能。
- 绑定关系工具保留在海报下方或右侧，不抢占主视觉。

## 合规边界

推广码文案不使用：
- 治疗、治愈、根治、消炎、抗癌、替代药物、替代诊疗。
- 保证效果、免费做全身任意部位。
- 虚假的报名人数、收益承诺或回本承诺。

可使用：
- 日常康养体验。
- 到店养护体验。
- 草本养护。
- 预约登记、禁忌确认、到店体验、建档回访。
- 好友报名、推广码、核销券。

## 实现范围

本轮只改前端：
- `frontend/src/App.vue`

不改后端数据模型和接口：
- 继续使用 `/user/invite-qr` 返回的 `inviteUrl`、`parentId`、`parentNickname`。
- 继续用 `qrcode` 生成二维码。

## 验收标准

- 登录后进入“邀请会员/我的推广码”，首屏能看到升级后的裂变海报。
- 二维码显示清晰，链接可复制。
- 移动端 390px 宽度无横向滚动。
- 海报内容不遮挡、不溢出，长邀请链接在说明区自动换行。
- `npm run build` 通过。
- 本地浏览器截图确认视觉方向接近 C 方案。
