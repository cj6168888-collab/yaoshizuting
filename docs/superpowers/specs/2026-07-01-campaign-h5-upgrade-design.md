# 裂变活动 H5 升级设计

## 目标

把现有“裂变活动”从信息展示页升级为门店可直接转发的拓客 H5。第一版重点跑通四件事：吸引客户、留下手机号、生成核销券、引导客户继续分享。

## 页面结构

公开活动页采用小程序式三栏结构：

- 首页：门店主视觉、活动利益点、价格、报名人数、门店电话和立即秒杀入口。
- 卡项：当前活动体验卡，包含领取方式、有效期、门店、报名人数和立即领取入口。
- 我的：展示当前手机号客户的核销券、推广码、好友/门店信息入口的轻量占位。

下单链路包含：

- 确认订单页：展示到店领取、门店电话、地址、活动卡项、备注和提交订单。
- 报名成功页：展示核销码、门店提醒、复制链接和分享推广卡。

## 文案方向

首页主文案：

- 全民健康中国行
- 经络调理体质体验免费做
- 到店体验经络仪调理 + 草本养护方案
- 限时领取，预约后到店核销

按钮文案：

- 立即秒杀
- 电话咨询
- 立即领取
- 提交订单
- 生成我的推广码
- 复制活动链接

后台模板：

- 9.9 体质调理体验
- 19.9 肩颈经络体验
- 0 元到店检测
- 老带新体验券

## 数据与接口

第一版不新增数据库表。继续使用：

- `gyt_partner_campaign`
- `gyt_campaign_signup`

接口增强：

- 同一活动、同一手机号重复报名时，不新增记录，直接返回原报名记录和核销码。
- 公开活动接口继续返回 `campaign`、`ownerNickname`、`shareUrl`。

## 视觉原则

参考小程序截图的青绿色主色、红色强转化按钮和底部三栏导航，但保留药师祖庭的稳重质感。页面不要做成后台卡片堆叠，要像一个面向客户的活动 H5。

## 第一版范围

包含：

- H5 首页升级
- 卡项页
- 确认订单页
- 报名成功页
- 我的页
- 后台活动模板文案
- 重复手机号报名防刷

不包含：

- 真支付
- 多商品商城
- 复杂分销佣金
- 微信小程序登录授权
- 访问量统计
