## 一、品牌加盟政策详情

### （一）店铺加盟

**加盟投入与启动支持**

- 投资金额：一次性投入 13,960元，即可正式成为品牌授权店铺
- 启动物资：费用已包含价值13,960元的首批货品，内含：1台专业仪器、20个大套盒(10支/盒)

**持续供货与弹性采购**

- 优惠补货：后续所有补货，均享受品牌标价 1.5折 的专属优惠
- 轻资产模式：可选"0元进货"仓储代发模式，按需下单，仅需支付 39.8元/套 的综合服务费

**全方位运营扶持**

- 专属爆卡导师提供 一对一 全程运营指导
- 享有 不限次数 的下店扶持服务

**市场拓展收益**

- 成功推广一家新店铺，即可享有开发 100家 新店铺的资格
- 自第二家起即可获得 9,000元/家 的市场推广奖励

### （二）代理加盟

**申请资格**：需已成功经营一家品牌店铺，深度认同品牌理念

- 代理费用：年度代理费为 39,800元
- 权益配置：即刻获赠1台专业仪器及20套套盒

**收益体系**

- 直推店铺奖励：9,000元/家
- 间推店铺奖励：6,000元/家
- 直推代理奖励：16,000元/个
- 直推合伙人奖励：16,000元/个

### （三）合伙人加盟

**申请资格**：需已成功经营一家品牌店铺，并具备卓越的市场管理与团队培训能力

- 合伙人费用：年度战略合作管理费 99,800元
- 权益配置：尊享获赠1台专业仪器及20套套盒
- 核心权利：经总部正式授权，享有在指定区域内招募与培训代理商的独家权利

**多元收益体系**

- 代理商管理培训费：您直接招募的每位代理商，将向您支付 39,800元 的管理培训费
- 直推店铺奖励：直接推广一家新店铺，奖励 9,980元
- 间推店铺奖励：团队内产生的间接推荐店铺，奖励 6,000元
- 直推合伙人奖励：直接推广一名合伙人，奖励 40,000元
- 团队管理津贴：您的整个团队中，自第2家至第100家店铺，您可持续享有 998元/家 的管理津贴

**代理商培训支持政策**

- 总部强力扶持：为助力您快速启动区域市场，总部将免费协助您完成为期X天的标准化培训，名额覆盖前10名代理商
- 质量共担机制：自第11名代理商起，为保障总部提供持续、高质的培训服务与资源支持，您需为每位新增代理商向总部支付培训支持费 9,800元/名

## 二、用户故事与场景

### 场景一：【店主视角】从消费者到创业者的"丝滑转身"

**用户角色**：王女士（美容院老板娘，寻求品牌转型）

1. **扫码加盟**：王女士在合伙人的推荐下，扫描了专属邀请码。小程序界面清晰显示"13,960元开启品牌授权"。她一键支付后，系统瞬间完成角色升级。

2. **物资落地**：支付完成的秒级瞬间，系统自动生成一张"启动大礼包"订单。王女士在后台看到：1台仪器、20个套盒已进入"待发货"状态，无需手动申请。

3. **经营无忧**：开业后，王女士需要补货。她打开小程序，发现所有产品自动显示为"1.5折"。她也可以选择"0元进货"模式，仅支付39.8元服务费，由总部云仓直接发货给她的客户。

4. **分享获利**：王女士推荐了闺蜜开店。当闺蜜支付成功，王女士的手机推送了一条消息："恭喜！您的市场推广奖励9,000元已到账，可随时提现。"

### 场景二：【代理视角】从单店经营到市场拓展的"身份跨越"

**用户角色**：李先生（已有一家店，渴望通过招募获利）

1. **资格校验与升级**：李先生在后台点击"申请代理"，系统后台逻辑引擎自动检测到他已拥有一家合伙门店，符合资格。他支付39,800元后，系统菜单瞬间多出了"团队管理"和"收益看板"两个模块。

2. **多维收益的体感**：李先生今天招募了一家新店，收益9,000元；他旗下的店主也招募了一家店，他惊喜地发现自己也收到了6,000元的"间推奖"。

3. **实时账单**：在"我的钱包"里，李先生可以看到每一笔分润的来源。

### 场景三：【合伙人视角】区域领袖的"战略管理"

**用户角色**：张总（具备团队领导力，追求区域独家权益）

1. **独家授权的归属感**：张总成为合伙人后，他在系统地图上锁定了自己的"战略领地"。他现在拥有了在区域内招募代理的"独家特权"。

2. **管理培训费的自动结算**：张总招募了一名新代理。代理支付的39,800元，系统识别到张总是其直接上级，这笔钱直接划入张总的"管理培训费"账户。

3. **阶梯成本的自动化触发**：当张总招募到第11个代理时，系统弹出温馨提示："由于您已成功孵化10名精英代理，后续每位代理将由总部提供深度培训支持，自动扣除9,800元支持费。"

4. **"睡后收入"的管道力量**：张总打开后台，看到"团队管理津贴"那一栏数字在跳动。

### 场景四：【总部/母体视角】全局掌控与自动化治理

**管理角色**：主人（系统最高权限者）

1. **策略的一键进化**：市场环境变化，主人在后台将"店主间推奖"从6,000元调整为6,500元。保存瞬间，全网数千名代理的预期收益实时同步。

2. **财务自动化闭环**：系统每天自动汇总各级分润，生成对账单。主人只需在后台轻轻一点"批量打款"，数百万的资金流转便通过API接口精准地流向每一个贡献者的钱包。

## 三、系统架构设计

### 核心定位

支撑"店-代-合"三位一体的自动化商业闭环

### 技术架构图

```
用户终端: 微信小程序/H5/Web
        ↓
API 网关 / 负载均衡
        ↓
核心业务层 - Spring Boot 3.x

[核心领域服务]
├── 用户中心: 身份识别/层级拓扑
├── 策略引擎: 动态价格/分润比例
├── 交易中心: 加盟支付/0元补货
└── 财务结算: 自动化分润/提现审核

[支撑层]
├── MySQL 8.0: 核心业务/关系链
├── Redis: 配置缓存/分布式锁
└── 消息队列 RocketMQ: 异步分润计算
```

### 技术栈

- 后端：Java 17, Spring Boot 3, MyBatis-Plus
- 安全：Spring Security + JWT
- 缓存：Redis
- 数据库：MySQL 8.0
- 消息队列：RocketMQ

## 四、数据库建模

### 1. 用户层级与身份表

```sql
CREATE TABLE `gyt_user_hierarchy` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `user_id` BIGINT NOT NULL UNIQUE,
    `role` ENUM('STORE', 'AGENT', 'PARTNER') NOT NULL,
    `parent_id` BIGINT DEFAULT 0,
    `tree_path` VARCHAR(1000),
    `agent_count` INT DEFAULT 0,
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_path` (`tree_path`)
) ENGINE=InnoDB;
```

### 2. 动态政策配置表

```sql
CREATE TABLE `gyt_config_policy` (
    `config_key` VARCHAR(64) PRIMARY KEY,
    `config_value` DECIMAL(12, 2) NOT NULL,
    `description` VARCHAR(255)
) ENGINE=InnoDB;
```

### 3. 财务流水与分润记录表

```sql
CREATE TABLE `gyt_profit_log` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `order_sn` VARCHAR(64) NOT NULL,
    `receiver_id` BIGINT NOT NULL,
    `contributor_id` BIGINT NOT NULL,
    `amount` DECIMAL(12, 2) NOT NULL,
    `type` ENUM('DIRECT_STORE', 'INDIRECT_STORE', 'AGENT_MANAGE', 'PARTNER_DIRECT', 'TEAM_MANAGEMENT', 'HEADQUARTER_SUPPORT_FEE'),
    `status` TINYINT DEFAULT 1,
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_order_type_receiver` (`order_sn`, `type`, `receiver_id`)
) ENGINE=InnoDB;
```

## 五、核心分润逻辑

### A. 加盟分润逻辑 (processJoinProfit)

**触发条件**：支付回调成功

**规则逻辑**：
1. 直接推荐奖：查询 parent_id 身份，根据政策表发放奖励（如店主推店主奖 9,000 元）
2. 间接推荐奖：通过 tree_path 向上追溯一级，判断是否符合间推条件
3. 管理津贴：若链路上存在合伙人，且当前店铺属于其团队（第2-100家），自动扣算 998 元

### B. 合伙人招募代理逻辑 (processAgentRecruitment)

**核心校验**：
1. 增加合伙人的 agent_count
2. 发放 39,800 元管理培训费
3. 判断阶梯：若 agent_count > 10，同步生成一笔负值的 gyt_profit_log，类型为 HEADQUARTER_SUPPORT_FEE (金额 9,800 元)，实现自动扣除

### 核心奖励金额表

| 场景 | 角色 | 奖励金额 |
|------|------|----------|
| 店主推荐店主 | 店主 | 9,000元/家 |
| 代理推荐店主 | 代理 | 9,000元/家 |
| 间推店铺 | 上级 | 6,000元/家 |
| 合伙人推荐店铺 | 合伙人 | 9,980元/家 |
| 合伙人招募代理 | 合伙人 | 39,800元/名 |
| 合伙人招募第11名+代理 | 总部扣费 | -9,800元/名 |
| 团队管理津贴 | 合伙人 | 998元/家（第2-100家） |
| 合伙人直推合伙人 | 合伙人 | 40,000元/名 |
| 代理直推代理 | 代理 | 16,000元/个 |
| 代理直推合伙人 | 代理 | 16,000元/个 |
