# UI Design Assets

This folder stores visual references used to guide frontend UI/UX implementation.

## imagegen-component-board.png

Generated with the built-in image generation tool as a high-fidelity reference board for the 药师祖庭 member management UI.

Prompt summary:
- Chinese SaaS/admin component board for wallet cards, team list, product rows, finance status chips, invitation QR card, and mobile navigation.
- Forest green, herbal green, warm gold accents, white panels, pale sage backgrounds.
- Dense, operational dashboard feel rather than a marketing landing page.
- Avoid decorative orbs, purple/blue gradients, cartoon style, and fake browser chrome.

Implementation notes:
- Use white data cards with small tinted icons instead of large solid-color blocks.
- Keep cards and controls at 8px radius.
- Prefer subtle borders and soft shadows over heavy decoration.
- Use status chips with restrained semantic colors.

## imagegen-admin-finance-board.png

Generated with the built-in image generation tool as a focused reference for the admin finance and operations screens.

Prompt summary:
- Production Chinese SaaS admin dashboard for 财务管理, 提现审核, 收益流水, 政策配置, and 货品管理.
- Compact filter bars, dense data tables, restrained semantic status chips, row actions, pagination, and a risk-warning policy panel.
- Deep green sidebar/action color, pale sage surfaces, warm orange risk accents, and white operational panels.
- Avoid one-note purple/blue gradients, rounded decorative hero sections, cartoon style, and oversized marketing composition.

Implementation notes:
- Make admin filter bars read like compact toolbars with pale surfaces and crisp controls.
- Keep table row actions small, tactile, and color-coded by intent.
- Use bordered status chips with low-saturation green, amber, and red fills.
- Treat configuration warnings as operational risk panels with a warm accent rather than loud alerts.

## imagegen-mobile-member-board.png

Generated with the built-in image generation tool as a mobile-first reference for the member H5/mini-app experience.

Prompt summary:
- Chinese mobile member center for wallet, withdrawal, team, invitation QR, product list, bottom tabs, status chips, and empty states.
- Deep medicinal green, fresh herbal green, warm gold, white cards, and pale sage background.
- Thumb-friendly controls, dense but readable cards, compact member operations, and clear bottom navigation.
- Avoid marketing hero layouts, purple/blue gradients, decorative orbs, cartoon style, and fake browser chrome.

Implementation notes:
- Use a fixed bottom navigation on small screens instead of a desktop sidebar squeezed into the viewport.
- Keep mobile cards compact, with clear hierarchy for balance, team, product, and invite states.
- Preserve 8px radius and restrained semantic chip colors on mobile.
- Increase tap targets while reducing ornamental spacing.

## imagegen-login-board.png

Generated with the built-in image generation tool as a focused reference for the login and session-entry experience.

Prompt summary:
- Mobile and desktop login screens for 药师祖庭会员管理系统.
- Phone/SMS login, code input row, quick test account chips, loading button, session error state, and brand header.
- Deep medicinal green, herbal green, warm gold, white login card, pale sage surface, and professional wellness operations tone.
- Avoid purple/blue gradients, decorative orbs, cartoon style, oversized hero composition, and fake browser chrome.

Implementation notes:
- Prefer a light herbal background with a crisp white login card over a heavy full-green page.
- Keep the SMS code action attached to the code input and sized as a clear touch target.
- Make quick test accounts read as role chips rather than plain text buttons.
- Keep mobile login spacing compact enough that the whole flow remains visible without awkward scrolling.
