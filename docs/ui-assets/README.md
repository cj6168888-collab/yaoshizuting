# UI Design Assets

This folder stores visual references used to guide frontend UI/UX implementation.

## imagegen-component-board.png

Generated with the built-in image generation tool as a high-fidelity reference board for the 药师祖庭 member management UI.

Prompt summary:
- Chinese SaaS/admin component board for wallet cards, team list, product rows, finance status chips, invitation QR card, and mobile navigation.
- Forest green, herbal green, warm gold accents, white panels, pale sage backgrounds.
- Dense, operational dashboard feel rather than a marketing landing page.
- Avoid decorative orbs, purple/blue gradients, cartoon style, and fake browser chrome.

Implementation notes:
- Use white data cards with small tinted icons instead of large solid-color blocks.
- Keep cards and controls at 8px radius.
- Prefer subtle borders and soft shadows over heavy decoration.
- Use status chips with restrained semantic colors.
