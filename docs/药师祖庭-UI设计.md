# 骨宜堂数字化系统前端UI详细设计文档

**设计理念**：轻盈、专业、信任  
**技术选型**：uniapp (兼容微信小程序/H5) + Tailwind CSS + NutUI (或 Element Plus)

---

## 一、全局视觉规范

- **主色调**：#B8860B (古铜金) —— 寓意骨宜堂的专业与价值感
- **辅助色**：#F5F5F5 (浅灰背景)、#FF4D4F (警示/金额)
- **字体**：系统默认黑体，金额部分采用中等加粗

---

## 二、核心页面设计

### 1. 首页：智慧看板 (Dashboard)

根据登录用户的 role（店主/代理/合伙人）动态展示不同的磁贴。

**顶部卡片**：
- 余额组件：实时显示"可提现余额"，点击进入提现页面
- 身份标签：右上角显著标注"品牌合伙人"或"授权店主"

**数据矩阵**：
- 今日收益：今日新增分润
- 团队规模：当前层级下的总人数
- 本月单量：成交的套盒/单品总数

**快捷入口**：[扫码邀请]、[产品补货]、[下店申请]、[培训课程]

### 2. 团队管理：可视化关系链 (Team Tree)

- 搜索框：支持按手机号/姓名精准搜索下级
- 层级列表：
  - 采用"手风琴"折叠结构
  - 店主/代理详情：显示该成员的加入时间、累计贡献业绩、所属区域
  - 合伙人特有逻辑：显示"已招募代理：12/10"，进度条展示，超过10人时高亮提醒总部支持模式已开启

### 3. 商城模块：弹性采购系统 (Inventory)

**双模式切换**：
1. 批量补货模式：系统自动计算 1.5折 后的价格，显示起订量
2. 云仓代发模式：显著标注"0元拿货"，每套固定结算 39.8元，填写客户地址后直接下单

**库存预警**：当账户绑定的虚拟库存不足时，红色文字提醒补货

### 4. 推广中心：流量裂变工具 (Growth)

- 专属海报：动态生成带用户 UID 的二维码海报
- 邀请记录：显示"潜在意向用户"（已扫码未支付）和"已转化伙伴"

## 三、关键交互逻辑

### 1. 身份驱动的 UI 渲染

```javascript
// 伪代码逻辑
const menuList = [
  { name: '区域招募', roles: ['PARTNER'], icon: 'rank' },
  { name: '管理津贴', roles: ['PARTNER', 'AGENT'], icon: 'money' },
  { name: '0元补货', roles: ['STORE', 'AGENT', 'PARTNER'], icon: 'box' }
];

const visibleMenu = menuList.filter(item =>
  item.roles.includes(currentUser.role));
```

### 2. 提现安全校验

- 提现金额需满足后台配置的最小值
- 点击提现时弹出"身份验证"或"支付密码"弹窗，确保资金安全
