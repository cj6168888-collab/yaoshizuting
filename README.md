## 📖 系统简介

药师祖庭会员管理系统是一个基于 Spring Boot 3 + Vue 3 构建的多级分润管理平台，支持店铺、代理商、合伙人三级加盟体系，实现了完整的加盟流程、分润计算、团队管理和财务结算功能。

### 核心特性

- ✅ **多级加盟体系** - 店铺、代理商、合伙人三级加盟
- ✅ **智能分润系统** - 直推奖励、间推奖励、团队管理津贴
- ✅ **实时钱包管理** - 余额查询、收益记录、提现管理
- ✅ **扫码锁定上下级** - QR码邀请、自动绑定、防循环关系
- ✅ **团队树结构** - 多级团队关系、业绩统计
- ✅ **支付集成** - 微信支付、支付宝支付
- ✅ **RBAC权限控制** - 基于角色的访问控制
- ✅ **分布式锁** - Redisson实现的并发控制
- ✅ **审计日志** - 完整的操作记录追踪

## 🚀 快速开始

### 方式一：Docker 部署（推荐）

```bash
# 克隆项目
git clone <repository-url>
cd yaishizuting

# 启动服务
docker-compose up -d

# 访问系统
# 前端: http://localhost:3001
# 后端: http://localhost:8090/api
```

### 方式二：手动部署

```bash
# 后端
mvn clean install
java -jar target/yaoshizuting-admin-1.0.0.jar

# 前端
cd frontend
npm install
npm run dev:h5
```

## ✨ 功能特性

### 1. 用户认证

- 📱 **短信验证码登录** - 无密码登录，安全便捷
- 🔐 **JWT Token** - 无状态认证，支持分布式部署
- 👥 **多角色管理** - 普通用户、店铺、代理商、合伙人、管理员

### 2. 加盟体系

#### 店铺加盟
- 加盟费: ¥13,960
- 直推奖励: ¥9,000
- 间推奖励: 根据配置

#### 代理商加盟
- 加盟费: ¥39,800
- 直推奖励: 根据配置
- 管理培训费: 根据配置

#### 合伙人加盟
- 加盟费: ¥99,800
- 直推奖励: 根据配置
- 团队管理津贴: 根据配置

### 3. 分润系统

#### 分润类型
- 💰 **直推店铺奖励** - DIRECT_STORE
- 💰 **直推代理奖励** - AGENT_MANAGE
- 💰 **直推合伙人奖励** - PARTNER_DIRECT
- 💰 **间推奖励** - INDIRECT_STORE
- 💰 **团队管理津贴** - TEAM_MANAGEMENT
- 💰 **总部培训支持费** - HEADQUARTER_SUPPORT_FEE

#### 分润特性
- ✅ 分布式锁防止重复分润
- ✅ 乐观锁保证余额一致性
- ✅ 支持并发场景下的正确分润
- ✅ 完整的分润记录追踪

### 4. 钱包管理

- 💳 **账户余额** - 实时查询
- 📈 **累计收益** - 总收益统计
- 📊 **收益记录** - 详细的分润明细
- 💸 **提现管理** - 申请、审核、打款

### 5. 团队管理

- 🌳 **团队树结构** - 可视化团队关系
- 👥 **成员管理** - 查看团队成员
- 📊 **业绩统计** - 团队业绩汇总
- 🏆 **角色标识** - 区分不同角色

### 6. 系统管理（管理员）

- ⚙️ **配置管理** - 动态调整系统参数
- 📋 **加盟费配置** - 调整各类加盟费用
- 💰 **分润配置** - 调整分润比例和金额
- 📊 **数据统计** - 用户、订单、分润统计

### 7. 扫码锁定上下级关系 (v1.1.0)

- 📱 **个人邀请QR** - 生成专属邀请链接
- 🔗 **绑定上级** - 新用户登录后绑定上下级
- 🔒 **锁定下级** - 上级扫描后锁定下级手机号
- 🛡️ **防循环绑定** - 禁止将下级/自己设为上级
- 🔐 **登录自动绑定** - 扫码后首次登录自动建立关系
- ⚡ **分布式锁保护** - 绑定操作防并发冲突

## 🔧 常见问题

### 1. 如何登录？

使用手机号 + 短信验证码登录。测试环境验证码存储在 Redis 中，可通过以下方式获取：

```bash
docker exec yaoshizuting-redis redis-cli get sms:code:13800000000
```

### 2. 如何修改系统配置？

使用管理员账号登录，在"系统管理"页面可以修改加盟费用和分润配置。

### 3. 如何查看分润记录？

登录后在"我的钱包"页面可以查看所有收益记录和详细信息。
